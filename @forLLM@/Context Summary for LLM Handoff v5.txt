2. 執行順序優化 (Commits: c81fcb6, 5de8695)
問題
原本的實現效率不佳：

# 舊方法：計算整個 network (1000 nodes)，再過濾
all_nodes = self.network.get_execution_order()  # O(N)
nodes_to_cook = [n for n in all_nodes if n.id in ancestor_ids]  # 可能只需要 5 nodes
解決方案
Node.execute() 優化 (c81fcb6)

新增 _get_local_execution_order(): 只對 ancestors + self 做局部拓撲排序
使用 Kahn's algorithm 直接處理子集
複雜度從 O(N) 降至 O(K)，K 為相關節點數
Network.get_execution_order() 重構 (5de8695)

重用 node._get_local_execution_order() 而非重複實現 Kahn's algorithm
對所有終端節點（無下游連接）做局部排序後合併
消除代碼重複，減少約 10 行代碼
