Critical Architecture Decisions
1. Method Naming: cook() vs compute()
Problem: BaseNode user method conflicted with NodeModel.cook()
Solution:

NodeModel.cook() - Public execution method (no parameters), called by framework
BaseNode.compute(**inputs) - Abstract method for user implementation (receives input values)
This separation prevents recursive calls and parameter mismatches
2. Signal System
Custom Signal class in nodegraph/core/signals.py
Uses weak references to prevent memory leaks
Handles parameter mismatch gracefully (tries with/without args)
Why: Keep Model layer Qt-independent for headless execution
3. Dirty Flag Propagation
Parameter changes mark node as dirty
Dirty propagates downstream through connections
Cook checks dirty flag and uses cached results when clean
Enables efficient lazy evaluation
4. Houdini Terminology
Network instead of "Graph"
Node instead of "Operator"
Connector instead of "Port" or "Pin"
Parameter instead of "Property"
Cook instead of "Execute" or "Evaluate"

Key Implementation Details
BaseNode Usage Pattern
from nodegraph.nodes.base import BaseNode

class MyNode(BaseNode):
    category = "Custom"
    
    def setup(self):
        """Define inputs, outputs, parameters"""
        self.add_input("a", data_type="float", default_value=0.0)
        self.add_output("result", data_type="float")
        self.add_parameter("multiplier", data_type="float", default_value=2.0)
    
    def compute(self, **inputs):
        """Implement node logic - DO NOT name this 'cook'!"""
        a = inputs.get("a", 0.0)
        mult = self.parameter("multiplier").value()
        return {"result": a * mult}
Execution Flow
User calls node.cook() or network.cook_all()
NodeModel.cook() checks dirty flag
If dirty, gathers input values from connected nodes
Calls _cook_internal(**input_values) → BaseNode.compute(**inputs)
Caches results and clears dirty flag
Returns success status
Topological Sorting
NetworkModel implements topological sort for execution order
Detects cycles and raises exceptions
Used by both cook_all() and PythonExporter
