⚙️ 核心算法 1：get_execution_order()
算法名称
Kahn's Algorithm (卡恩算法) - 拓扑排序

目的
计算节点的正确执行顺序，确保依赖项在被依赖者之前执行

输入/输出
输入: 无（使用网络中的所有节点）
输出: List[NodeModel] - 按拓扑顺序排列的节点列表
算法实现（已优化版本）
def get_execution_order(self) -> List[NodeModel]:
    """
    使用 Kahn's 算法进行拓扑排序
    时间复杂度: O(V + E)
    空间复杂度: O(V)
    """
    nodes = self.nodes()
    if not nodes:
        return []
    
    # 节点ID映射（因为节点对象不可哈希）
    node_map = {node.id: node for node in nodes}
    
    # 使用 defaultdict 简化初始化
    in_degree = defaultdict(int)      # 入度表：记录每个节点有多少个前驱
    adjacency = defaultdict(list)     # 邻接表：记录每个节点的后继
    
    # 构建图结构
    for node in nodes:
        # 确保所有节点都初始化（即使没有边）
        if node.id not in in_degree:
            in_degree[node.id] = 0
        
        # 遍历所有输出连接
        for output_conn in node.outputs().values():
            for connected_input in output_conn.connections():
                if connected_input.node:
                    target_node = connected_input.node
                    adjacency[node.id].append(target_node.id)
                    in_degree[target_node.id] += 1
    
    # 使用 deque 作为队列（O(1) popleft）
    queue = deque(node.id for node in nodes if in_degree[node.id] == 0)
    sorted_nodes = []
    
    # Kahn's 算法主循环
    while queue:
        node_id = queue.popleft()  # O(1) vs list.pop(0) O(n)
        sorted_nodes.append(node_map[node_id])
        
        # 减少后继节点的入度
        for neighbor_id in adjacency[node_id]:
            in_degree[neighbor_id] -= 1
            if in_degree[neighbor_id] == 0:
                queue.append(neighbor_id)
    
    # 环路检测：如果排序的节点数少于总节点数，说明有环
    if len(sorted_nodes) != len(nodes):
        cyclic_nodes = [node for node in nodes if node not in sorted_nodes]
        cyclic_names = [node.name for node in cyclic_nodes]
        raise ValueError(
            f"Cyclic dependency detected in network '{self.name}'. "
            f"Nodes in cycle: {', '.join(cyclic_names)}. "
            f"Cannot determine execution order."
        )
    
    return sorted_nodes
关键数据结构
数据结构    类型  用途
in_degree   defaultdict(int)    记录每个节点的入度（有多少个前驱）
adjacency   defaultdict(list)   邻接表，记录每个节点的后继节点
queue   deque   存储入度为0的节点（可执行节点）
sorted_nodes    list    最终的拓扑排序结果
算法步骤可视化
示例图:

A → B → D
↓     ↘
C       E
执行过程:

初始状态:
in_degree = {A:0, B:1, C:1, D:1, E:2}
queue = [A]

步骤1: 处理A
  - sorted_nodes = [A]
  - B入度: 1→0, C入度: 1→0
  - queue = [B, C]

步骤2: 处理B
  - sorted_nodes = [A, B]
  - D入度: 1→0, E入度: 2→1
  - queue = [C, D]

步骤3: 处理C
  - sorted_nodes = [A, B, C]
  - queue = [D]

步骤4: 处理D
  - sorted_nodes = [A, B, C, D]
  - E入度: 1→0
  - queue = [E]

步骤5: 处理E
  - sorted_nodes = [A, B, C, D, E]
  - queue = []

结果: [A, B, C, D, E] ✅
性能优化历史
优化前:

in_degree = {node.id: 0 for node in nodes}    # 手动初始化

对于 N 个节点，总体从 O(N²) 改进到 O(N)
🔍 核心算法 2：has_cycle()
算法名称
DFS + 递归栈 - 深度优先搜索环路检测

目的
检测有向图中是否存在环路（循环依赖）

输入/输出
输入: 无（使用网络中的所有节点）
输出: bool - True 表示有环，False 表示无环
算法实现
def has_cycle(self) -> bool:
    """
    使用 DFS + 递归栈检测环路
    时间复杂度: O(V + E)
    空间复杂度: O(V)
    """
    visited = set()      # 全局访问标记（所有访问过的节点）
    rec_stack = set()    # 递归栈（当前DFS路径上的节点）
    
    def visit(node_id: str) -> bool:
        """DFS访问函数"""
        visited.add(node_id)        # 标记为已访问
        rec_stack.add(node_id)      # 加入当前路径
        
        # 检查所有子节点（出边）
        node = self._nodes[node_id]
        for child in self.find_child_nodes(node):
            if child.id not in visited:
                # 情况1: 子节点未访问过 → 递归访问
                if visit(child.id):
                    return True  # 子树中发现环
            elif child.id in rec_stack:
                # 情况2: 子节点在当前路径上 → 发现环！
                return True
            # 情况3: 子节点已访问但不在当前路径 → 安全，跳过
        
        # 回溯：从当前路径移除
        rec_stack.remove(node_id)
        return False
    
    # 遍历所有节点（处理不连通的图）
    for node_id in self._nodes:
        if node_id not in visited:
            if visit(node_id):
                return True
    
    return False  # 没有发现环
核心判断逻辑表
条件  含义  操作  原因
child not in visited    从未访问过   递归访问    探索新节点
child in rec_stack  在当前路径上  返回 True（环）  发现回边
child in visited 且不在 rec_stack  已在其他路径访问    跳过  交叉边，安全
为什么需要两个集合？
集合  作用  不能省略的原因
visited 记录所有访问过的节点  避免重复访问，提高效率（尤其对不连通图）
rec_stack   记录当前DFS路径   检测"回边"（指向祖先的边），这是环的标志

应用场景
在 connect() 方法中被调用，防止创建环路：

def connect(self, source_node_id, source_output, 
            target_node_id, target_input) -> bool:
    # ... 获取连接器 ...
    
    # 先尝试连接
    success = source_connector.connect_to(target_connector)
    
    if success:
        # 检查是否产生环路
        if self.has_cycle():
            # 撤销连接
            source_connector.disconnect_from(target_connector)
            print(f"Warning: Connection from {source_node.name}.{source_output} "
                  f"to {target_node.name}.{target_input} would create a cycle")
            return False  # 拒绝环路连接
        
        # 连接成功且无环
        self.connection_added.emit(source_connector, target_connector)
        self.network_changed.emit()
    
    return success

Optimize get_execution_order() with defaultdict and deque

- Improves performance from O(n) to O(1) for queue operations in Kahn's algorithm
